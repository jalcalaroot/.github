# .github

Default community health files for every repository under [@jalcalaroot](https://github.com/jalcalaroot).

GitHub automatically uses these files in any repository that does not have its own copy:

| File | Purpose |
|---|---|
| [SECURITY.md](SECURITY.md) | How to report vulnerabilities privately |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to contribute, plus the rules for infrastructure code |

A repository that needs different rules can add its own file with the same name, which overrides the default.
